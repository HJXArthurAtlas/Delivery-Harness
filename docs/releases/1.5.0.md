# 1.5.0 发版说明（2026-11-06）

## 规格侧主链重排

- 主链定为 intend → clarify → grill，clarify 在 grill 之前（能力分工：clarify 补定义、grill 压力测试）
- intend 收尾链式询问「继续 clarify?」，clarify 收尾链式询问「继续 grill?」，选中即自动执行
- `/che-grill` 与 `/che-grill-with-docs` 同链位二选一（后者额外沉淀术语 / ADR）

## 链式交互契约（全链统一）

- 所有交接提问强制走 AskUserQuestion 工具，禁止纯文本输出后中断等待
- 提问统一两选项（继续 / 就此停下），去掉「退出」项；每个选项带一句话动作说明
- 选中即由 agent 在本会话自动执行目标技能（携带 TASK_DIR / SLUG），用户无需手动敲命令
- 问句只描述动作，不出现技能名

## PingCode 集成改造

- 建卡挂点（after_intend）从 clarify 阶段移至澄清链尾：grill（或 grill-with-docs）收尾问「是否现在推送到 PingCode?」，同意即自动执行 `/che-pingcode-specstoissues` 建卡并登记 mapping，拒绝或未配置静默跳过、不阻塞交接
- 任务卡挂点（after_tasks）改为 plan 收尾条件问「根据 tasks.md 补建任务卡?」，同意即自动补建
- 卡片一致性对账（before_implement）保持 implement 入向静默前置不变

## 动态流程提示

- grill 收尾按 intent 内容动态判定是否存在 UI 需求（拿不准按涉 UI），只提示下一步 `/che-design`（涉 UI）或 `/che-plan`（无 UI），不再展示双分支让用户自选

## 开发侧主链调整

- plan 主链纳入 `/che-analyze`：plan → analyze → gapfill → planverify；analyze 新增 Handoff（目标 gapfill），存在 CRITICAL 发现时先建议修正再继续
- gapfill 收尾按 gate 实际配置分流（口径与 che planverify-gate 一致）：门禁开启（adr_gate 默认 block 或 planverify_gate block）以主流程提问「继续 planverify?」；双 gate off 则静态提示直接 implement，planverify 降为可选
- planverify PASS 收尾只输出单行「下一步：/che-implement」，gate 前置说明不再外显

## 文档与版本

- 同步三份指南至新流程：AI Native 实践指南 §3.2（主线链条 / mermaid / 产品与开发侧步骤 / 质量环节表）、技能交接流程（全图 / Handoff 要点表 / 挂点表 / 承重机制）、校验技能对比（交互 / 下游 / 流水线图）
- 版本 bump：根 package.json、omp 插件 marketplace.json、指南版本对齐行 → 1.5.0

## CLI 变化

- 无（CLI 维持 0.4.0，本版无 `packages/cli` 改动）
